# PC-002 — Prompt Feedback flow on the single Detection Prompt model

- Status: **IMPLEMENTED — VERIFIED (static)** (owner approved 2026-10-29; implemented 2026-10-29)
- Created: 2026-10-29
- Owner: Delaney Foley
- Related: PC-001 (Single Detection), PDEC-014–PDEC-022
- Related requirements: the Post-HIL "Prompt Improvement Assistant" (Run
  Analysis) surface and `/api/gemini` feedback suggestions.

## Request

Bring the **Prompt Feedback** flow (the "Prompt Improvement Assistant" in
[PostHilMetrics.tsx](../../src/components/PostHilMetrics.tsx) + the `/api/gemini`
suggestion generator + `prompt_feedback_template`) onto the PC-001 single
Detection Prompt model, so post-HIL AI suggestions edit the one Detection Prompt
and save a composition-backed Single Detection version — consistent with Prompt
Assist, Compare, and Iteration.

## Current behavior

- `/api/gemini` (POST) renders `prompt_feedback_template` with
  `CURRENT_DECISION_POLICY` / `CURRENT_DECISION_RUBRIC` /
  `CURRENT_USER_PROMPT_ADDENDUM`, runs the VLM over sampled FP/FN/parse-fail
  images, and returns `suggestions: PromptEditSuggestion[]` whose `section` is
  one of `decision_policy` / `decision_rubric` / `user_prompt_addendum`.
- [PostHilMetrics.tsx](../../src/components/PostHilMetrics.tsx) filters to those
  sections, lets the reviewer accept/reject, applies `old_text → new_text`
  replacements to `label_policy` / `decision_rubric` / `user_prompt_addendum`,
  and creates a new version carrying those `prompt_structure` fields. It then
  runs a GOLDEN-set regression (pre-edit vs candidate).

## Desired behavior

- For a composition-backed **Single Detection** source version, the only tunable
  field is the **Detection Prompt** (the target member description). The feedback
  analyzer returns `section: "detection_prompt"` edits (`old_text → new_text`)
  against the current Detection Prompt; the reviewer accepts/rejects; accepted
  edits are applied to the Detection Prompt; a new **composition-backed** Single
  Detection version is saved (member description = edited Detection Prompt),
  running via the aggregate single-member path.
- No `decision_policy` / `decision_rubric` / system-prompt suggestions for a
  single-detection source.
- The GOLDEN-set regression check is preserved (it already runs through the
  composition-aware run path from PC-001).

## Scope

1. **Backend** ([gemini/route.ts](../../src/app/api/gemini/route.ts)): when the
   source version is composition-backed, pass the current Detection Prompt
   (target member description) to the analyzer and instruct it to return only
   `detection_prompt` edits. Keep the legacy policy/rubric/addendum path for
   non-composition (legacy) versions.
2. **Feedback template** ([adminPrompts.ts](../../src/lib/adminPrompts.ts),
   `renderPromptFeedbackTemplate`): add a single-detection rendering that
   supplies the current Detection Prompt and asks for `detection_prompt` edits.
   Keep the existing template for legacy sources.
3. **Frontend** ([PostHilMetrics.tsx](../../src/components/PostHilMetrics.tsx)):
   for a composition-backed source, accept the `detection_prompt` section, apply
   accepted `old_text → new_text` edits to the Detection Prompt, and save a
   composition-backed version (one-member composition + frozen snapshot +
   production label), mirroring Compare/Iteration. Legacy sources keep today's
   behavior. Add a `detection_prompt` label in `formatSectionLabel`.

Non-goals:
- No change to the GOLDEN regression mechanics (reused as-is).
- No change to legacy non-composition versions' behavior (forward-only).
- No change to the separate HIL note diagnosis (`/api/hil/diagnose-note`) or
  other AI flows.
- No production-planning (`aidlc-docs/`) changes.

  policy/rubric/addendum feedback behavior.
- PDEC-025: Preserve the GOLDEN-set regression check (runs via the
  composition-aware run path).

## Acceptance criteria

1. On a Single Detection run, "Get Suggestions" returns only `detection_prompt`
   edits; no policy/rubric/system-prompt sections appear.
2. Accepting suggestions and saving creates a new composition-backed Single
   Detection version whose target member description reflects the applied edits,
   in the same version group (next `_V#`).
3. The saved version runs via the aggregate single-member path (presence
   semantics), and the GOLDEN regression (pre-edit vs candidate) still executes.
4. Legacy (non-composition) versions retain their current feedback behavior.
